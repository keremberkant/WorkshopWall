# Changelog

## 1.1.0 — 2026-11-07

- **Renamed to WorkshopWall** (was *Canlı Duvar*). The new app has its own bundle ID; on first launch it takes over the
  old app's settings and library automatically. Turn *Launch at login* on again if you used it, and delete the old
  *Canlı Duvar* app.
- Eight original sample web wallpapers in `examples/` (Aurora, Caustics, Synthwave, Dunes, Nebula, Lava Lamp, Silk, Bokeh)
- `examples/water-waves` moved to `templates/water-waves`
- README with screenshots, FAQ and a guide to making your own wallpaper
- Security policy and pull request template

## 1.0.0 — 2026-11-07

First public release.

- Plays Wallpaper Engine video, web and image wallpapers behind the desktop icons, on every display and Space
- One shared hardware video decoder for all displays
- Global shortcuts (⌃⌥⌘ ← → ↓), previous / next / random, Dock menu, menu bar menu
- Steam Workshop downloads with SteamCMD (sign-in happens in Terminal, never in the app)
- Automatic pausing: display sleep, battery, Low Power Mode, covered desktop
- Library on any folder or external drive, drag & drop import, async thumbnails, search
- English and Turkish
