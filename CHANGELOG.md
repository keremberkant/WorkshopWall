# Changelog

## 1.0.0 — 2026-11-07

First public release.

- Plays Wallpaper Engine video, web and image wallpapers behind the desktop icons, on every display and Space
- One shared hardware video decoder for all displays
- Global shortcuts (⌃⌥⌘ ← → ↓), previous / next / random, Dock menu, menu bar menu
- Steam Workshop downloads with SteamCMD (sign-in happens in Terminal, never in the app)
- Automatic pausing: display sleep, battery, Low Power Mode, covered desktop
- Library on any folder or external drive, drag & drop import, async thumbnails, search
- English and Turkish
